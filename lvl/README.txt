План POLYGON: 6 задач

Level 0 — HTTP Recon
Разминка

Знакомство с вебом
Участник изучает главную страницу, заголовки и robots.txt, находит маршрут /admin.
Чему учится: HTTP, curl, маршруты и разведка.
Проверка: при достижении учебного маршрута приложение пишет [FLAG_SUCCESS] level-0-recon.
Это именно вводная задача, а не полноценная уязвимость.




Level 1 — Information Disclosure
Раскрытие информации
Веб-приложение случайно публикует резервную конфигурацию с тестовыми данными.
Чему учится: искать ошибки настройки и понимать последствия утечки данных.
Проверка: маркер записывается после того, как участник действительно получил защищённый учебный файл, а не просто ввёл его предполагаемый URL.




Level 2 — IDOR
Нарушение контроля доступа
API позволяет просмотреть заказ другого тестового пользователя из-за отсутствия проверки владельца объекта.
Чему учится: разнице между аутентификацией и авторизацией, работе API и пользовательских сессий.
Проверка: фиксируется успешное получение чужой записи в тестовом сценарии.



Level 3 — SQL Injection
Инъекция в запрос к базе данных
Форма поиска использует небезопасно сформированный SQL-запрос.
Чему учится: SQL, параметризованным запросам и границе между данными и исполняемым синтаксисом.
Проверка: фиксируется получение заранее подготовленной записи, недоступной при обычной логике запроса.




Level 4 — Command Injection
Выполнение системных команд
Твой текущий Flask-сервис с ping, subprocess и намеренным shell=True.
Чему учится: shell, Linux-процессам, правам пользователя и ограничению возможностей контейнера.
Проверка: используется подтверждение выполнения дополнительной команды, например через уникальный маркер конкретного запроса, а не просто поиск символа ;.




Level 5 — XSS
Выполнение JavaScript в браузере
Приложение сохраняет пользовательский комментарий и небезопасно вставляет его в HTML.
Чему учится: HTML-экранированию, контекстам вывода и последствиям выполнения недоверенного JavaScript.
Проверка: отдельныйтестовый браузер подтверждает выполнение безвредного контрольного JavaScript и отправляет сигнал в лабораторию. Одной проверки строки запроса здесь недостаточно.
